## 📘 Descripción del Proyecto

Este proyecto integra los **Talleres 1, 2 y 3** desarrollados durante el curso, implementando un **backend completo en Node.js con Express**.

Todos los endpoints son de tipo **POST** y reciben sus parámetros mediante el **body** en formato JSON.
